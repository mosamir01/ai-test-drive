Privacy Policy

shortsfactory, the publishing tool of the AI Test Drive YouTube channel. Effective October 24, 2026.

Who uses this app

shortsfactory is a private tool. Only the owner of the AI Test Drive channel uses it, to publish that channel's own videos. It is not offered to anyone else.

What Google data it accesses

Through YouTube API Services, with the channel owner's permission, shortsfactory:

  • uploads videos to the owner's channel and sets their title, description, tags, privacy and publish time;
  • reads the processing status of those uploads and the channel's list of uploads;
  • reads the channel's YouTube Analytics reports, such as views, watch time, likes, comments, shares and subscribers gained.

How the data is used

Only to publish and schedule the channel's own videos and to measure how they perform. It is not used for anything else.

Storage and sharing

The sign-in token is stored only in the macOS Keychain on the owner's computer. Video statistics are stored in a local database on that computer. Nothing is sold, used for advertising, or shared with anyone, except where the law requires it.

shortsfactory's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Viewers

People who watch the channel interact with YouTube, not with this tool. shortsfactory collects no data about viewers beyond the totals in the channel's own YouTube Analytics reports.

YouTube API Services

shortsfactory uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Removing access and data

Access can be revoked at any time at myaccount.google.com/permissions. Local data is deleted when the channel stops using the tool, or on request.

Contact

Questions about this policy: open an issue on GitHub.
